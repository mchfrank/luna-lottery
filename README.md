# Лотерея племени Луны

Статический сайт для GitHub Pages + Supabase.

## Важное про купоны

Коды купонов НЕ хранятся в GitHub. Они должны быть заполнены в таблице `coupons` в Supabase.

`config.js` содержит только URL проекта Supabase и публичный anon key. Это нормально для клиентского сайта.

Никогда не помещайте в `config.js` service-role key.

## Установка

1. Создайте бесплатный проект Supabase.
2. Откройте SQL Editor.
3. Выполните `supabase.sql`.
4. Затем выполните `seed_coupons.sql`.
5. В таблице `coupons` заполните `coupon_code` для каждой строки.
6. В Supabase -> Settings -> API скопируйте Project URL и anon/public key.
7. Вставьте их в `config.js`.
8. Загрузите содержимое этой папки в GitHub.
9. В GitHub включите Pages из ветки с сайтом.

## Как это защищено

- Один нормализованный вариант имени может выиграть только один раз.
- Проверка и выдача происходят на сервере Supabase.
- Выдаваемый купон блокируется транзакцией.
- В публичном списке победителей нет кодов купонов.
- Таблица купонов не доступна для прямого чтения через anon API.
- Значение купона возвращается только в ответе на успешный розыгрыш.

## Ограничение

Имя персонажа само по себе не является надёжной аутентификацией личности. Если человек знает чужое имя и вводит его первым, сайт не сможет отличить владельца персонажа.

Если нужна защита именно от этого, следующим этапом можно добавить подтверждение через Discord/Telegram/код участника или отдельный админский механизм.
